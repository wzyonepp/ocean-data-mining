# 已见查询上的边界对齐探索

本目录保存原站点优先、站点边界对齐、时间优先的同批测量。108 条查询的 1,620 次计时外，增加 Q0 全表扫描的 15 次计时；327 次答案检查通过。

这是已见查询上的探索轮，不是新的独立验证。协议和方法在 protocol.json、plan_frozen.md；写入接口重建原文件逐字节一致的证据为 writer_control.json。measurements.csv 保存预热和计时，query_summary.csv 为逐查询统计。联合匹配诊断发生在全部计时之后，不是读取器实际 I/O 跟踪。

原验证日期组相对站点优先观察到 16.65% / 23.60% 的类别均值收益，但时间优先仍更低。后续新日期验证另在 alignment_fresh_v1/，不能只选择探索阶段较好的幅度进行报告。文件字节、48 个行组和额外尾部短组等成本在 layouts.json。三个图表提供 PNG/PDF。

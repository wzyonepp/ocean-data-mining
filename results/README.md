# 结果与证据

当前文件属于数据源筛查结果，尚非 Parquet 性能实验结果。

- [数据筛查清单](data_screening_manifest.json)：16 个文件的来源、校验值、时间范围、记录数与缺测统计。
- [数据访问过程记录](data_access_notes.md)：403、临时 503 及最终完成情况。
- [数据筛选说明](../report/03_data_selection.md)：站点汇总和实验适用边界。

本次实测共 734,800 条记录，其中非缺测水温记录 713,823 条，水温缺测 20,977 条，站点与时间重复键为 0。每个输入文件的 SHA-256 和筛查脚本哈希已核对。

后续性能结果应另行保存原始测量值、配置、数据版本和软件版本；本目录说明中的筛查数字不能当作查询性能结论。
